# rida.me

Personal CV / portfolio site. Plain HTML + CSS, no build step, no framework — just `index.html` and `styles.css`.

## Editing

Open `index.html` and edit directly. Generic text like "Company Name" / "City, Country" under "Experience" is example structure — replace with your actual work history. Adjust Skills and Projects to match what you want to highlight.

## Local preview

No server required — just open `index.html` in a browser, or serve it locally:

```bash
python3 -m http.server 8000
```

## Deployment

This repo is published via GitHub Pages from the `main` branch root.
